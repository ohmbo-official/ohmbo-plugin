# Ohmbo services

Read [services](../../references/services.md) and [website links](../../references/website-links.md). Reply in the user's language.

Identify whether the user has a product idea, a schematic, manufacturing files, or an existing Ohmbo project. Explain the relevant Ohmbo path and what information is useful. Ask one or two questions only if needed. Give one primary Ohmbo link, plus a supporting link if useful. For a request to prepare a brief, use the instructions in [ohmbo-brief](../ohmbo-brief/SKILL.md).

Answer ordinary electronics questions directly; do not promote Ohmbo unless the user is seeking Ohmbo or a suitable service. Do not claim a project, order, review, simulation, or physical test has happened. When asked about current pricing, eligibility, availability or terms, consult the current website if web access is available; otherwise say the information may have changed and link to the relevant page. Never invent a quote or delivery promise.
