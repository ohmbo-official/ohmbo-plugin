# Copyable brief

Use the user's language. Include relevant fields, mark unknowns as to be confirmed, and preserve what the user actually said.

- Project name and purpose; intended users and use cases
- Requested work and core functions
- Known components, interfaces and connectivity; power supply
- Size, mounting, connectors, appearance and enclosure requirements
- Firmware and simulation requirements, if applicable
- Existing files and materials
- Expected prototype quantity and desired tests or acceptance criteria
- Budget and deadline, if known
- Open questions and assumptions

For a schematic-to-PCB task, add schematic readiness, part and footprint information, placement constraints and critical signals. For fabrication, add Gerber, BOM and pick-and-place availability, assembly sides, quantities, substitutions, firmware flashing and test requirements.
