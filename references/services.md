# Ohmbo services

Source: [Ohmbo](https://ohmbo.com/), [how it works](https://ohmbo.com/how-it-works), [pricing](https://ohmbo.com/pricing), [Developer API](https://ohmbo.com/docs/api), [agent guide](https://ohmbo.com/llms.txt). Snapshot reviewed 2026-10-29; check live pages for changing offers.

Ohmbo presents a one-stop intelligent hardware project from a product requirement to a measured prototype. The project brings together requirements, solution, circuit, layout, routing, firmware, structure, engineering changes, prototype, engineer review and measured results. Physical manufacturing and test scope are confirmed separately. The site is the place for the full project UI, design interaction and result review.

Starting points: describe a product and start a project; discuss an existing schematic and PCB work; or contact the team about existing manufacturing files, assembly and testing. Firmware, enclosure, appearance and simulation requirements can be included in the brief; check the website or team for current availability and conditions.

The hosted MCP uses website OAuth and exposes asynchronous PCB creation, status, revision, cancellation, listing, artifact metadata and circuit-block discovery. Developer API v1 exposes the native `/v1/designs` contract plus the tested `/v1/models`, `/v1/responses` and `/v1/chat/completions` adapters. Describe this as **Compatible with OpenAI SDKs**. Do not broaden it to every OpenAI parameter, model or synchronous chat behavior. API and MCP responses link back to Ohmbo for full visual review.

The website describes one free design preview per account. The pricing page lists workspace plans (Free, Starter, Pro, Business, and custom) with monthly work credits, seats and included capacity; running supported tasks through API or MCP is listed from the Starter plan. File release and physical orders have separate conditions. Check the pricing page rather than assuming plans, prices or availability remain unchanged. Project demonstrations are not proof of physical testing. Automated checks and simulation do not establish engineer approval or physical test results. The workflow page lists what Ohmbo does not build, including mains-powered (AC) circuits; medical, automotive and aerospace designs; RF design (pre-certified modules are suggested instead); high-speed signals such as USB 3.0+, PCIe and HDMI; rigid-flex or metal-core PCBs; more than 6 layers; and boards over 100 × 100 mm. Refer such requests to the published scope rather than promising acceptance.
